# 前端重构设计：ChatGPT 风格浅色 UI

## 概述

将现有深色极客风格的 AI 聊天机器人前端，重构为简洁浅色风格（类似 ChatGPT）。
保留所有后端接口不变，仅重写前端三个文件。

## 核心变更

### 1. 配色方案

| 元素 | 颜色 | 说明 |
|------|------|------|
| 主背景 | `#F9FAFB` | 浅灰 |
| 侧边栏背景 | `#F3F4F6` | 稍深灰 |
| 卡片/消息背景 | `#FFFFFF` | 白色 |
| 主色调 | `#10A37F` | 绿色（按钮/用户消息） |
| 主文字 | `#1F2937` | 深灰 |
| 辅助文字 | `#6B7280` | 中灰 |
| 边框 | `#E5E7EB` | 浅灰 |

### 2. 布局

左侧边栏 (~260px) + 右侧主内容区（自适应宽度）。
移动端（<768px）侧边栏收起为汉堡菜单。

### 3. 功能卡片交互

四个功能卡片（天气、数学、搜索、时间）改为可点击：
- 点击后自动填入示例问题到输入框
- 聚焦输入框，用户确认后发送
- hover 时轻微上浮 + 阴影加深

示例问题映射：
- 天气 → "北京今天天气怎么样？"
- 数学 → "计算 23 * 45 + 128"
- 搜索 → "搜索最新的 AI 技术进展"
- 时间 → "现在几点？今天是星期几？"

### 4. 文件变更

| 文件 | 操作 |
|------|------|
| `templates/index.html` | 完全重写 |
| `static/style.css` | 完全重写 |
| `static/app.js` | 完全重写（保留所有业务逻辑） |

后端代码不做修改。

### 5. 保留功能

- SSE 流式对话
- 会话管理（新建、切换、删除）
- 设置面板（模型选择、API Key、Base URL）
- Markdown 渲染（代码块、粗体、链接等）
- 消息复制 + 重新生成
- 移动端响应式
